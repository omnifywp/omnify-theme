WordPress Compatibility

🔷

WordPress 6.5+

Requires WordPress 6.5 or later. Full Site Editing supported.

🐘

PHP 8.1+

Requires PHP 8.1 or later. PHP 8.2+ recommended for best performance.

🗄️

MySQL 5.7+ / MariaDB 10.3+

Compatible with MySQL 5.7 or later and MariaDB 10.3 or later.

Developer Tools

🔌 REST API

Full REST API for headless and custom integrations. Manage products, orders, and customers programmatically.

📥 Import / Export (CSV)

Bulk import and export products and orders via CSV for easy data migration and management.

🔑 API Keys Management

Generate and manage API keys for third-party integrations directly from the WordPress admin.

📋 Activity Log

Track admin actions and system events with a built-in activity log for auditing and debugging.

🔔 Webhooks [placeholder]

Send real-time event notifications to external services. Verify availability before publishing.

🖥️ Hosting

OmnifyWP runs on any standard WordPress hosting that meets the PHP and MySQL requirements listed above. No special hosting is required.
