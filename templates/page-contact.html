Support

Get support

OmnifyWP is a self-hosted WordPress plugin. For questions, bug reports, and feature requests:

  • WordPress.org Support Forum — primary support channel
    wordpress.org/support/plugin/omnifywp-ecommerce/
  • GitHub Issues — for confirmed bug reports
    github.com/omnifywp/omnifywp-ecommerce/issues
  • Documentation — for setup and configuration guides
    View documentation →
  • Commercial support options may be available — check the plugin page for current information.

Before opening a support ticket

Running through this checklist first helps resolve most issues quickly and leads to faster responses from the support team.

  • Check the FAQ — common questions are answered on our Homepage FAQ and in the documentation.
  • Search existing forum threads — your question may already be answered on the WordPress.org support forum.
  • Review the documentation — visit the Documentation page for step-by-step guides.
  • Note your WordPress and PHP versions — include these in your support request under Dashboard → Updates and Tools → Site Health.
